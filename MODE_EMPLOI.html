5. Évaluer un CCF EP3

1
Bascule sur le pôle ✅ Évaluer → CCF EP3

Ou clic direct sur la carte d'un élève dans la vue d'ensemble.

2
Choisis l'élève dans le menu

Si déjà sélectionné via clic sur la carte, c'est déjà fait.

3
Coche le niveau pour chaque tâche

4 colonnes : NA (rouge) · EC (orange) · A (vert) · PA (bleu).
25 tâches au total réparties en 4 blocs : 0 sécurité (30 pts), A fluidiques (120), B mesures (100), C documentation (50).
La note se calcule en temps réel : (total brut × 20) / 280 = note finale sur 20.

Clic sur une cellule déjà cochée = désélectionner. Bouton ↺ Effacer pour reset complet.

Sauvegarde automatique : chaque modification est enregistrée 0,4 s après la dernière action. Tu peux fermer l'onglet, tout est conservé localement.
