1Objectifs de la séance 2

Objectif général : approfondir la maîtrise SC/SR en distinguant les points locaux et totaux sur un schéma cycle frigorifique simplifié, et savoir interpréter l'écart entre les deux.
Objectifs opérationnels — l'élève sera capable de :
  • Identifier sur un schéma cycle frigorifique les 4 emplacements de mesure (T asp · T Se · T Scd · T det).
  • Calculer la surchauffe locale (Tasp − T0) et la surchauffe totale (TSe − T0).
  • Calculer le sous-refroidissement local (TK − TScd) et le sous-refroidissement total (TK − Tdet).
  • Interpréter l'écart entre SC locale et SC totale (gain de chaleur dans la ligne d'aspiration → isolation suspecte si trop grand).
  • Diagnostiquer un dysfonctionnement spécifique (filtre déshydrateur bouché → SR total ≠ SR local avec écart Tdet).

3Prérequis & Matériel

Prérequis élèves (séance 1 acquise) :
  • Lecture P0 / PK sur manomètres BP/HP.
  • Déduction T0 / TK via cadran multi-fluides.
  • Formules de base : Surchauffe = TSe − T0 · SR = TK − TScd.
  • Diagnostic basique (sain / manque fluide / surcharge).
  • Connaissance du cycle frigo : 4 organes + 2 lignes (HP / BP).
Matériel pour la séance :
  • Fiche élève imprimée — 2 pages A4 (manos page 1 + schéma page 2).
  • Fiche d'évaluation par compétences (1 page paysage par diplôme).
  • Crayons / stylos couleur rouge · orange · bleu · violet (placement des 4 points).
  • Calculatrice.
  • Vidéoprojecteur — projection du schéma vide pour démo placement.

5Différenciation pédagogique & Évaluation

Différenciation prévue :
  • À soutenir : placement des points en autonomie, mais on simplifie à 2 calculs (SC totale + SR local) au lieu de 4. Pas de calcul SC locale ni SR total exigé.
  • Standard : les 4 calculs en autonomie + interprétation simple.
  • Rapide : proposer un 2e jeu de valeurs (modifié au crayon par le prof) avec un dysfonctionnement à diagnostiquer.
  • DYS / TDAH : code couleur ①②③④ explicite, validation prof intermédiaire avant chaque phase, table P/T agrandie.
Modalités d'évaluation :
  • Formative : validation prof du placement des points avant calculs (cohérence pédagogique).
  • Note /20 : Lectures (4) + Placement (6) + Calculs (6) + Interp. (4).
  • Par compétences : feuille dédiée selon diplôme (NA / EC / A / M).
  • Auto-évaluation : cases en bas de fiche cochées par l'élève.
  • Bilan séance 1 + 2 : comparer la progression entre les 2 séances.
